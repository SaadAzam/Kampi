## 3. Architecture changes

### Dependency direction

```text
apps/web, apps/game-*  →  @kampi/game-sdk/{client,embed,common}
apps/realtime          →  @kampi/game-sdk/{server,common} + game-*-core packages
packages/game-penalty, game-rps-core  →  pure rules/manifests (no Phaser, no DB)
```

### `@kampi/game-sdk` subpaths

- `common` — manifests, seats, queue keys, clock/RNG, `SdkError`
- `client` — `GameSessionClient` (queue, private invite, join, reconnect, `request_snapshot`)
- `server` — `GameRegistry`, `SettlementCoordinator`, `CommandGuard`, `DeadlineScheduler`
- `embed` — host/game bridge (root re-exports kept for BC)
- `testing` — fakes/harness helpers

### Game modules

- `@kampi/game-rps-core` — RPS manifest/schemas; RPS room registers via registry
- `@kampi/game-penalty` — Penalty rules, config Zod, bot pick, progress decisions
- `apps/game-penalty` (`@kampi/game-penalty-app`, port **5174**) — Phaser + DOM a11y/e2e overlays

### Realtime

- Multi-game lobby queues keyed by `game|version|mode|stake|region`
- Human-first public matchmaking; bot fill after configured delay
- Private invites via Colyseus Presence/Redis TTL (`apps/realtime/src/sessions/private-invite.ts`)
- `PenaltyDuelRoom` — concealed pending actions, timeouts, sudden death, forfeit/abort, settlement coordinator
- RPS migrated onto seats A/B + shared settlement

### Platform

- Seed registers `penalty-duel` + `clientLaunchUrl` in version config
- API `/games` resolves launch URL from catalog config (env fallback)
- Web lobby: `POST /auth/guest`, catalog cards, embed session without token query string
- Fixed Nest DI: `@Inject(AppConfigService)` on `AuthController` / `GamesController` (guest auth was 500)

### Deviations

- No new Prisma migration — existing `Game` / `Match` / ledger models reused; Penalty history in `MatchEvent` payloads
- Playwright browser E2E requires API + realtime + Vite on 5174; CI unit gate does not start those services. Live Colyseus tests are opt-in via `KAMPI_LIVE_E2E=1`
- Vite `--host 127.0.0.1` used when sandbox blocks `os.networkInterfaces()`
